## Arquitectura de autenticación

### Backend
- JWT con access token (1h expiración)
- Endpoints: `/api/v1/auth/register`, `/api/v1/auth/login`, `/api/v1/auth/me`
- bcrypt para hashing de contraseñas
- Storage in-memory de usuarios (sin DB aún)
- CORS habilitado para frontend
- ValidationPipe global con whitelist

### Frontend
- AuthService con login/register/logout
- AuthInterceptor agrega token a requests HTTP
- AuthGuard protege rutas privadas
- Token en localStorage
- LoginComponent con toggle login/register
- HomeComponent con logout
