  - CatalogModule: Búsqueda en RAWG API
  - LibraryModule: Gestión de biblioteca personal

- **Endpoints**:
  - `/api/v1/auth/*` - Autenticación

## Bug crítico resuelto

### JWT Secret Configuration
- **Problema**: Error 401 al acceder a endpoints protegidos
- **Causa**: JWT_SECRET se evaluaba antes de cargar .env
- **Solución**: Crear constants.ts para centralizar carga
- **Impacto**: Todos los endpoints de biblioteca ahora funcionan correctamente
