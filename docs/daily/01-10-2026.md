## Problemas encontrados

### 1. Error 401 en endpoints de biblioteca
- **Problema**: Usuarios autenticados recibían 401 al acceder a library endpoints
- **Causa**: JWT_SECRET se evaluaba antes de cargar .env en algunos módulos
- **Solución**: Centralizar carga de JWT_SECRET en constants.ts
- **Aprendizaje**: Las variables de entorno deben cargarse antes de cualquier inicialización de módulos

### 2. Conflicto de merge en LIB-002
- **Problema**: develop y main divergieron
- **Solución**: Merge de main en develop, luego crear rama desde develop actualizado
- **Aprendizaje**: Siempre verificar que develop esté actualizado antes de crear ramas de feature
