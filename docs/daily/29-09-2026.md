## Problemas encontrados

### 1. CORS bloqueado
- **Problema**: Frontend no podía comunicarse con backend (puertos diferentes)
- **Solución**: `app.enableCors()` en main.ts de la API

### 2. Tests e2e fallaban con ESM
- **Problema**: Jest no podía transformar paquetes ESM de @nestjs
- **Solución**: Configurar `transformIgnorePatterns` en jest-e2e.json

### 3. Loading state no se reseteaba en error
- **Problema**: Botón se quedaba en "Cargando..." cuando el servidor respondía con 400
- **Solución**: Usar `ChangeDetectorRef.detectChanges()` y `catchError` para manejar errores y resetear loading sincrónicamente. Primer intento con `NgZone` y `finalize` no funcionó.

## Decisiones tomadas

- Token almacenado en localStorage del navegador
- Rutas protegidas con AuthGuard funcional
